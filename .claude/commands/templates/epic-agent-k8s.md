# K8s Agent Context

> Include when the agent is working on Kubernetes manifests, Kustomize overlays, or ArgoCD applications.

## Validation Steps

Before creating the PR, run these checks:

### Kustomize Build
```bash
# Verify all overlays render cleanly
cd /Users/nick/Code/{REPO}
kustomize build k8s/base/ > /dev/null 2>&1 && echo "base: OK" || echo "base: FAIL"

# If overlays exist
for env in staging prod; do
  if [ -d "k8s/overlays/$env" ] || [ -d "k8s/base/overlays/$env" ]; then
    kustomize build "k8s/overlays/$env/" > /dev/null 2>&1 && echo "$env: OK" || echo "$env: FAIL"
  fi
done
```

### YAML Validation
```bash
# Verify YAML syntax on all changed files
git diff --name-only origin/main | grep -E '\.ya?ml$' | while read f; do
  python3 -c "import yaml; yaml.safe_load(open('$f'))" 2>&1 && echo "$f: OK" || echo "$f: FAIL"
done
```

## K8s Best Practices Checklist

When creating or modifying manifests:

- [ ] **Resource limits**: Every container must have `resources.requests` and `resources.limits`
- [ ] **Security context**: Pods should have `securityContext.runAsNonRoot: true`, containers should have `allowPrivilegeEscalation: false`
- [ ] **Health probes**: Deployments need `livenessProbe` and `readinessProbe`
- [ ] **Labels**: All resources must have `app.kubernetes.io/name`, `app.kubernetes.io/part-of`, `app.kubernetes.io/managed-by`
- [ ] **PodDisruptionBudget**: Deployments with >1 replica need a PDB
- [ ] **Anti-affinity**: Multi-replica Deployments should prefer spreading across nodes
- [ ] **Rolling update**: Use `maxUnavailable: 0, maxSurge: 1` for zero-downtime
- [ ] **Namespace**: Resources deploy to the correct namespace
- [ ] **Kustomization**: New resources added to `kustomization.yaml`

## dk-alchemy Conventions

- Infrastructure components live in `k8s/infrastructure/{component}/`
- Each component has `base/` and optionally `overlays/{staging,prod}/`
- Reusable components in `k8s/components/` (hpa, pdb, doppler-secret, etc.)
- ArgoCD Applications auto-generated by ApplicationSets — don't create Application CRDs manually
- DopplerSecret CRD for secrets — never hardcode secrets in manifests

## Product Repo K8s Convention (dk-data-fe, behavior-labs-ai)

```
k8s/
  base/
    kustomization.yaml          # lists all base resources
    {service}/
      deployment.yaml
      service.yaml
      ...
  overlays/
    staging/kustomization.yaml  # patches for staging
    prod/kustomization.yaml     # patches for prod
```

ArgoCD Application points to `k8s/overlays/{env}/` via the `.gitops/` directory.

# dk-alchemy PR Content Generation

**Status:** Complete

## Context
When a new product repo is created from dk-template, it needs to be registered with dk-alchemy (ArgoCD bootstrap, Grafana alert routing). Rather than making teams write these files manually, dk-template generates them in a `_dk-alchemy-pr/` directory ready to be submitted as a PR.

## Scope
- External app bootstrap YAML (prod + staging)
- AppProject bootstrap YAML
- Grafana contact point addition
- Grafana notification policy route addition
- PR instructions README

## Dependencies
- Plan 01 (Core Scaffold) — init.sh processes these files too

## Implementation Steps

### Step 1: Create `_dk-alchemy-pr/README.md`
```markdown
# dk-alchemy Integration PR

These files were generated by `dk-template` for **{{product}}**.

## How to Submit

1. Fork or clone [dk-alchemy](https://github.com/data-kinetic/dk-alchemy)
2. Create a branch: `git checkout -b onboard/{{product}}`
3. Copy these files into dk-alchemy:
   ```bash
   cp -r _dk-alchemy-pr/.gitops/ /path/to/dk-alchemy/.gitops/
   ```
4. Manually merge the contact point and notification policy additions into the existing files:
   - `grafana/provisioning/alerting/contact-points.yaml` — add the entry from `contact-points-addition.yaml`
   - `grafana/provisioning/alerting/notification-policies.yaml` — add the route from `notification-policies-addition.yaml`
5. Add the new AppProject and bootstrap to the kustomization:
   - Edit `.gitops/repositories/kustomization.yaml` — add `{{product}}-bootstrap.yaml` to resources
6. Commit, push, and open a PR

## Files Included

| File | Destination in dk-alchemy | Purpose |
|------|--------------------------|---------|
| `.gitops/external/{{product}}-prod.yaml` | `.gitops/external/` | ArgoCD bootstrap (production) |
| `.gitops/external/{{product}}-staging.yaml` | `.gitops/external/` | ArgoCD bootstrap (staging) |
| `.gitops/repositories/{{product}}-bootstrap.yaml` | `.gitops/repositories/` | AppProject + credentials |
| `contact-points-addition.yaml` | Merge into `grafana/provisioning/alerting/contact-points.yaml` | Slack alert channel |
| `notification-policies-addition.yaml` | Merge into `grafana/provisioning/alerting/notification-policies.yaml` | Alert routing rule |

## After Merging

Once the dk-alchemy PR is merged:
- ArgoCD will detect the new Application and begin syncing
- Grafana alerts for {{product}} services will route to the team's Slack channel
- The product repo's `.gitops/prod/apps/` and `.gitops/staging/apps/` will be managed by ArgoCD
```

### Step 2: Create `_dk-alchemy-pr/.gitops/external/{{product}}-prod.yaml`
```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: {{product}}-prod-bootstrap
  namespace: argocd
  labels:
    app.kubernetes.io/part-of: dk-external-apps
    tenant: {{product}}
spec:
  project: {{product}}-bootstrap
  source:
    repoURL: https://github.com/data-kinetic/{{repo-name}}
    targetRevision: main
    path: .gitops/prod/apps
  destination:
    server: https://kubernetes.default.svc
    namespace: argocd
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
      - ServerSideApply=true
      - RespectIgnoreDifferences=true
    retry:
      limit: 3
      backoff:
        duration: 5s
        factor: 2
        maxDuration: 3m
```

### Step 3: Create staging variant (`{{product}}-staging.yaml`)
Same as prod but targetRevision: staging, path: .gitops/staging/apps

### Step 4: Create `_dk-alchemy-pr/.gitops/repositories/{{product}}-bootstrap.yaml`
```yaml
apiVersion: argoproj.io/v1alpha1
kind: AppProject
metadata:
  name: {{product}}-bootstrap
  namespace: argocd
spec:
  description: "Bootstrap project for {{product}} — allows creating Applications and ApplicationSets only"
  sourceRepos:
    - https://github.com/data-kinetic/{{repo-name}}
  destinations:
    - namespace: argocd
      server: https://kubernetes.default.svc
  clusterResourceWhitelist:
    - group: argoproj.io
      kind: Application
    - group: argoproj.io
      kind: ApplicationSet
```

### Step 5: Create contact-points-addition.yaml
```yaml
# Add this entry to dk-alchemy/grafana/provisioning/alerting/contact-points.yaml
- name: {{product}}-slack
  type: slack
  settings:
    recipient: "#{{product}}-alerts"
    token: ${GRAFANA_SLACK_TOKEN}
    title: |
      {{ `{{ template "default.title" . }}` }}
    text: |
      {{ `{{ template "default.message" . }}` }}
```

### Step 6: Create notification-policies-addition.yaml
```yaml
# Add this route to dk-alchemy/grafana/provisioning/alerting/notification-policies.yaml
# under the existing routes array:
- receiver: {{product}}-slack
  matchers:
    - team = {{team}}
  group_by:
    - alertname
    - severity
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 4h
```
